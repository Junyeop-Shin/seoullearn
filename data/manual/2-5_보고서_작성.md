# 2-5. 보고서 작성

## 보고서 제출 기한
<!-- page: 26 | type: 공통 -->

- 멘토링 활동 후 7일 이내 제출하는 것이 원칙이다.
- 보완 요청을 받은 날로부터 7일 이내에 재제출해야 한다.
- 습관적·반복적으로 제출기한을 지키지 않으면 연장 승인 불가 처리 또는 멘토단 활동 제한을 받는다.
- 활동보고서를 지연 제출하면 활동비가 정상적인 일정에 지급되지 않을 수 있으며, 온라인 장기활동가산금 구간 산정 시 제외될 수 있다.

## 보고서 종류별 작성 방법
<!-- page: 26 | type: 공통 -->

| 구분 | 언제 | 무엇을 | 어디에 | 언제까지 |
| --- | --- | --- | --- | --- |
| 종합계획서① | 멘토링 시작 전. 온라인은 일정 협의 후, 오프라인은 장소 예약 후 | 멘토링 차시별 일정 | 플랫폼에 직접 작성 | 매칭 후 7일 이내 |
| 종합계획서② | 멘토링 한 번 진행 후. 1차시 활동 후 활동보고서를 업로드할 때 | 목표, 차시별 진도, 과제 등 1회기 멘토링의 모든 것 | 별도 서식에 작성 후 1차시 첨부파일에 업로드 | 1차시 활동보고서 제출기한과 동일 |
| 활동보고서 | 멘토링 진행 중. 매 차시 멘토링 활동 후 | 차시별 멘토링 진행 내용 | 플랫폼에 직접 작성 + 출결증빙 첨부파일 | 차시별 활동 종료 후 7일 이내 |
| 완료보고서 | 멘토링 완료. 마지막 차시 활동보고서 승인 직후 | 1회기 멘토링 총정리 | 플랫폼에 직접 작성 | 마지막 차시 활동보고서 승인 직후 |

## 1회기 보고서 타임라인
<!-- page: 27 | type: 공통 -->

1회기(16회차, 약 4개월) 동안 기간별로 작성해야 하는 보고서의 종류와 개수다.

| 시기 | 작성할 보고서 | 개수 |
| --- | --- | --- |
| 사전준비 (매칭 직후) | 사전 종합계획서 (홈페이지 마이페이지 → 해당 멘티 클릭 → 종합계획서 작성) | 1개 |
| 1회차 (멘티와의 첫 만남) | 1회차 활동보고서 + 종합계획서 파일 (서식은 홈페이지 → 마이페이지 → 공지사항에서 한글·워드 파일로 다운로드) | 2개 |
| 2~15회차 (매주 멘토링 활동, 주 1회 1시간, 9~22시 사이) | 주간 활동보고서. 매 회차 활동 후 7일 이내 작성, 첨부파일로 증빙사진 첨부 (시작 1개 + 종료 1개 = 총 2개) | 매주 1개 |
| 16회차 (마무리) | 16회차 활동보고서 + 완료보고서. 완료보고서 작성 버튼은 관리자의 16회차 승인 완료 후 생성 | 2개 |

- 15회차 무렵 멘토링 연장 버튼이 활성화된다. 15~16회차 동안 멘티와 상의해 연장 여부를 결정한다.
- ※ '연장신청' 버튼은 멘토링이 최종 2번 남았을 때 생성된다.

## 종합계획서① (사전 종합계획서)
<!-- page: 28 | type: 공통 -->

- 매칭 직후, 멘티와 본격적인 멘토링을 시작하기 전에 플랫폼에 직접 입력하는 종합계획서로, 일정 생성용이다.
- 온라인 그룹은 일정만 협의되면 작성할 수 있지만, 오프라인 그룹은 담당자의 장소 예약이 완료된 후에 작성할 수 있다.

### 입력 항목과 작성 예시

- 멘토링 시간(60분) 선택
- 학습 요일 선택
- 학습목표, 학생진단, 멘토링 구성, 활동규칙: 멘토 본인 기준에서의 종합계획 작성
  - 학습목표 예시: 멘티의 학습사이트 강좌 진도 관리(약 20~25강), 영어 문법 기본개념 학습
  - 학생진단 예시: 통화로는 구체적인 파악이 힘드나 문법 학습을 희망함. 1회차에 자세한 상담 예정
  - 멘토링 구성 예시: 시작 10분 온라인 강의 수강 확인 및 퀴즈 / 10분 문제 풀이 및 복습 / 30분 개념 학습 / 10분 오답풀이 및 다음 회차 안내 등
  - 활동규칙 예시: 멘토링 시간 준수하기 등
- 회차별 커리큘럼 작성 (회차별 일시는 자동으로 설정됨)
  - 예시: (온라인 강의) 1회차 수업 진도 확인 / (멘토링 내용) 영어문장 구조의 이해, 명사 / (진학상담) 영어영문학과 전공과목 알아보기

## 사전 종합계획서 작성 시 홈페이지 사용 주의사항
<!-- page: 29 | type: 공통 -->

- 홈페이지에서 사전 종합계획서를 작성해 등록하면 별도 담당자 승인 절차 없이 작성 완료가 되어 **수정이 불가**하다. 일정을 신중히 고려해 등록해야 한다.
- 사전 종합계획서 등록 시 다음 두 가지 경우 홈페이지 오류가 발생할 수 있다.
  - 특수문자가 포함된 경우
  - 내용이 많은 경우
- 사전 종합계획서 등록 후 일정 변경은 **1회차 일정만** 가능하다.
- 여러 건의 일정 변경이 필요하면 이음단 선생님께 별도로 문의한다.
- ※ 사전 종합계획서 수정 및 일괄 일정 변경 기능은 향후 보완 예정이다.

## 종합계획서② (종합계획서 파일)
<!-- page: 29 | type: 공통 -->

- 1회차 멘토링 후 종합계획서 파일을 작성하여 1회차 활동보고서와 함께 첨부파일로 7일 이내에 등록한다.
- ※ 서울런 홈페이지 공지사항에서 서식을 다운로드한 후 작성한다.
- 멘토링 기간 동안의 학습 과목, 일정, 멘티의 학습 수준, 학습목표, 멘티가 수강 중인 온라인 강의, 활동규칙 등을 작성한 후 멘티에게 공유한다.
- 서식 항목: 멘토링 기간, 멘티, 멘토, 멘토링 과목 및 시간, 멘티 학습목표, 멘티 진단, 커리큘럼(회차별), 멘토링 구성, 활동규칙 (상세는 부록 서식 참고)

## 활동보고서
<!-- page: 30 | type: 공통 -->

- 각 회차마다 1개의 보고서를 작성해 7일 내 홈페이지에 등록한다. 1회기당 총 16건의 활동보고서를 작성한다.
- 멘티가 수강 중인 온라인 강의의 진도 진행 상황을 반드시 기재한다.
- 각 회차별 인증사진 2개(시작/종료) 첨부가 필수다. (출결 인증은 4-3 활동 인정 기준 p.48 참고)
- **출결인증 미비, 보고서 등록기한 미준수 시 활동비가 지급되지 않는다.**

### 항목별 작성 방법과 예시

| 항목 | 필수 기재 사항 | 예시 |
| --- | --- | --- |
| 멘토링 과목 및 시간 | 과목, 학습사이트 강좌명, 실제 진행 시간 | 수학: 메가스터디 수학의 시작, 시발점 - 수Ⅰ / 시간: 17:10 ~ 18:09 |
| 이번 회차 학습 내용 | 학습범위(혹은 목차), 학습목표 필수 기재 | 학습범위: 거듭제곱근과 지수법칙 / 학습목표: 거듭제곱근의 개념을 이해하고 지수법칙을 적용하여 식을 계산할 수 있다 |
| 학습진도 | 출결, 학습사이트 수강 여부 확인 내용, 과제 수행 여부 필수 기재 | 출결: 5분 전 도착 / 인강: 거듭제곱근과 지수법칙(4강 미수강, 3강 수강) / 과제: 인강 교재를 수강 범위만큼 풀고 채점했으나 오답 풀이는 미진행 |
| 학습이해도 | 멘토링 학습 내용 필수 기재 | 1. 학교 수행평가 준비로 인강을 계획만큼 수강하지 못함. 미수강 회차는 과제로 부여(다음 멘토링 시간까지 수강) 2. 인강으로 예습이 진행되어 거듭제곱근 개념 설명을 잘 이해함. 지수법칙을 능숙하게 활용하도록 계산 문제 풀이 반복 진행 3. 인강 교재 오답 풀이 결과 단순 계산 실수가 잦은 편임 |
| 기타 | 필요한 경우 학습사이트, 멘토링 공간, 멘토링 진행 관련 내용 등 기재 | 서울런 홈페이지에서 멘토링 진행 시 화상회의 시스템 튕김 현상이 발생합니다. 조치 부탁드립니다. |

- 학습진도와 학습이해도는 매우 잘함 / 잘함 / 보통 / 노력필요 / 매우 노력필요 5단계로 평가한다.
- 진행 시간은 예정된 시간이 아니라, 지체 혹은 조기 진행된 경우를 반영해 **플랫폼 접속시간과 일치하는 실제 시간**으로 작성한다. (예: 17:00~18:00이 아닌 실제 접속시간 17:10~18:09)

## 완료보고서
<!-- page: 31 | type: 공통 -->

- 1회기(16회차) 종료 후 멘토링 활동에 대한 결과를 보고한다.
- 16회차 활동보고서 작성 후 관리자 승인이 완료되면 16회차 보고서 작성 화면이 '완료보고서'로 바뀐다. 클릭하여 완료보고서를 작성하고 제출한다.
- 멘토링 연장 신청 버튼은 최종 2번의 멘토링이 남았을 때 생성된다.
- 멘토링 연장 여부와 상관없이 멘토링을 완료하면 완료보고서를 반드시 작성해야 한다.
- 연장 진행 그룹이 완료보고서를 작성(및 승인)하지 않으면 시스템상 연장 회기(새로 시작하는 회기)가 진행되지 않는다.

### 항목별 작성 방법과 예시

| 항목 | 필수 기재 사항 | 예시 |
| --- | --- | --- |
| 멘토링 수행 리스트 | 16회차 분, 회차별 진행일시(시간) | 1회차: 23.05.14(일) 09:00~10:00 / 60M |
| 학습목표 | 종합계획서에 기재한 학습목표 + α | 메가스터디 수학의 시작, 시발점(현우진) 수Ⅰ을 완강한다 / 기말고사 수학 시험에서 3등급을 달성한다 / 단순 계산 실수를 줄이고 고득점 문제의 해결 능력을 기른다 |
| 멘토링 내용 | 학습 외 습관 및 태도, 진로·진학 탐색 내용 | 학습 플래너 작성과 자율학습 습관 형성 / 희망 대학 및 전공 관련 입시·진학 정보 탐색 / 멘티에게 유리한 대학별 입시 전형 탐색 |
| 학습목표 대비 성취도 | 출결, 과제 수행, 인강 수강, 학습 진도 등 학습목표 | 시발점 수Ⅰ 완강 / 수Ⅰ 1회독 완료, 주교재 및 부교재 풀이 완료 / 학습플래너 작성과 인강 수강 습관 적용 중 / 목표대학 결정, 입학정보 탐색 |
| 감성케어 상담 | 학습 및 진로, 정서 관련 상담 내용 (권장 기재) | 친구와의 다툼으로 우울해하는 멘티에게 멘토 경험을 바탕으로 슬기롭게 극복하도록 응원 / 부모님의 과도한 기대로 스트레스를 받는 멘티에게 정서적으로 도움이 되는 책·영화 소개 |
| 멘티 요청사항 및 해결과정 | 멘티 요청과 해결 과정 | 목표 대학을 궁금해하는 멘티를 위해 심화활동으로 캠퍼스 탐방 진행 / 자율학습이 익숙하지 않다는 멘티를 위해 캠스터디를 제안하여 함께 공부 |
| 멘토링 연장 의사 | 멘토, 멘티 각각 택1 | 기존 멘티(멘토)와 연장 희망 / 새로운 멘티(멘토)와 매칭 희망 / 연장 희망하지 않음 |

## 보고서 작성 체크리스트
<!-- page: 32 | type: 공통 -->

보고서 작성 시 빠진 것이 없는지 확인한다.

| 구분 | 번호 | 확인 내용 |
| --- | --- | --- |
| 종합계획서 | 1-1 | 멘토링 기본 정보(멘티 성명, 멘토링 과목, 학습사이트 강좌명, 일정 등)를 정확하게 작성했다. |
| 종합계획서 | 1-2 | 학습목표 항목에 학습사이트 수강목표와 진로·진학 목표를 작성했다. |
| 종합계획서 | 1-3 | 멘티 진단 항목에 멘티의 멘토링 과목 역량과 학습 수준, 학습 태도에 대해 상담하고 평가한 내용을 작성했다. |
| 종합계획서 | 1-4 | 학습사이트 강의를 바탕으로 회차(주차)별 커리큘럼 항목을 작성했다. |
