# 서울런과 서울런 멘토링 소개

## 서울런이란?
<!-- page: 3 | type: 공통 -->

서울런 회원은 강좌를 최대 3개까지 수강할 수 있고, 맞춤 공부를 위한 멘토링도 받을 수 있다. 서울런은 학습자원 접근이 어려운 청소년에게 다양한 교과, 비교과, 공공연계 학습콘텐츠를 온라인으로 제공하며, 온·오프라인 멘토링을 통해 학습관리와 정서적 지지를 제공한다.

### 가입 대상

- 서울시 거주 만 6세 ~ 만 24세
- 중위소득 60% 이하, 법정 한부모가족, 학교 밖 청소년, 다문화가족, 국가보훈대상, 북한이탈주민 청소년, 건강장애학생, 관외 아동복지시설 입소 아동
  - 중위소득 60% 이하: 수급권자, 차상위계층, 중위소득 50% 초과 60% 이하
  - 법정 한부모: 중위소득 63% 이하 (단, 청소년 한부모 가정은 중위소득 72% 이하)
  - 가족돌봄청년: 중위소득 120% 이하

### 학습 콘텐츠

| 구분 | 과정 | 학습사이트 |
| --- | --- | --- |
| 교과 (택1) | 초등과정 | 홈런 초등, 엘리하이, 밀크T 초등, 스마트올 |
| 교과 (택1) | 중등과정 | 온리원, 엠베스트, 밀크T 중학, 홈런 중등 |
| 교과 (택1) | 고등과정 | 이투스, 메가스터디, 밀크T 고등, 대성마이맥 |
| 교과 (택1) | 검정고시 | 에듀윌 |
| 전문강좌 (택1) | 어학·자격증·기타 | 에듀윌, 해커스, 패스트캠퍼스 (중등 이상 수강 가능) |
| 독서 (택1) | 전자책·오디오북 | 윌라 |
| 추가 | 중고등과정 | 강남인강 |
| 추가 (AI) | 중고등과정 | 콴다 |

### 가입 방법

서울런 홈페이지(slearn.seoul.go.kr)에 접속해 자격검증을 거친 뒤 가입이 승인된다.

## 서울런 멘토링이란?
<!-- page: 4 | type: 공통 -->

서울런 멘토링은 서울런 학습콘텐츠와 연계한 1:1 맞춤형 온·오프라인 멘토링이다. 서울런 멘토는 멘티의 공부 계획, 진도 관리 등 체계적인 학습을 지도하는 **학습 플래너**이자, 학교생활과 진로·진학 고민을 함께 나누는 **친한 선배** 역할을 한다.

### 멘토링 체계

| 구분 | 내용 |
| --- | --- |
| 온라인 멘토링 | 서울런 전용 화상 플랫폼 활용 |
| 오프라인 멘토링 | 연계 스터디카페, 공공시설 등 장소 활용 |
| 멘티 | 멘토와 1:1 매칭, 학습습관과 진로·진학 상담 |
| 멘토 | 멘티의 학습진도 및 커리큘럼 관리 |

### 멘토의 역할

| 역할 | 내용 |
| --- | --- |
| 학습 플래너 | 공부계획, 진도관리, 맞춤지도 |
| 친한 선배 | 학교생활, 진로상담, 경험공유 |
