# 서울런 멘토 업무 지원 도구 제안

서울런 멘토의 반복 업무(매뉴얼 문의, 활동보고서·종합계획서·완료보고서 작성, 멘토 교체 인계)를 줄이는 도구를 만들었습니다. 멘티와 멘토의 이름을 멘토의 브라우저 밖으로 내보내지 않고 보고서 내용을 서버에 저장하지 않는 구조이며, 지금은 가상 데이터로 동작을 확인한 시제품 단계입니다. 한 자치구에서 시범 운영할 기회와 활동가이드 사용 허락을 요청드립니다.

- 제안자: (이름, 소속, 멘토 활동 기간을 적어 주세요)
- 수신: 서울시 교육지원정책과, 서울런 멘토링 운영사무국
- 작성일: 2026년 10월

## 1. 왜 필요한가

멘토는 멘토링 외에 다음 일을 반복합니다.

- **규정 확인:** 활동가이드는 60쪽이 넘고 공지가 수시로 추가됩니다. 지각 처리, 결석 증빙, 일정 변경 기한 같은 것을 그때그때 찾아야 하고, 못 찾으면 운영사무국이나 이음단에 문의합니다.
- **보고서 작성:** 회차마다 활동보고서를 7일 안에 내고, 회기마다 종합계획서를 두 번, 완료보고서를 한 번 씁니다.
- **인계:** 멘토가 바뀌면 다음 멘토는 멘티의 수강 진도와 학습 습관을 처음부터 다시 파악합니다.

운영 측에서는 같은 문의가 여러 멘토에게서 반복되고, 보고서 보완 요청이 생깁니다.

> (동료 멘토 설문 결과를 넣을 자리: 응답자 수, 매뉴얼 확인과 보고서 작성에 드는 시간, 가장 번거로운 일)

## 2. 무엇을 만들었나

| 기능 | 멘토가 하는 일 | 도구가 하는 일 |
| --- | --- | --- |
| 매뉴얼 질문 | 평소 말투로 질문 | 활동가이드와 공지에서 답을 찾아 쪽수와 함께 답합니다. 답이 없으면 지어내지 않고, 문의처와 보낼 글의 초안을 줍니다 |
| 활동보고서 | 회차에 있었던 일을 메모하듯 입력 | 계획과 선택으로 칸을 미리 채우고, 제출 기한과 필요한 증빙을 안내합니다. 결석 회차에는 학습 내용을 만들지 않습니다 |
| 종합계획서 | 항목별로 짧게 적고, 학년·과목을 고르거나 강의 목차를 붙여 넣음 | 서식의 형식대로 정리하고, 교육과정 단원이나 강의 목차를 주차에 나눠 커리큘럼을 채웁니다 |
| 완료보고서 | 화면을 열고 초안을 고침 | 저장해 둔 종합계획서와 활동보고서로 플랫폼의 네 칸 초안을 씁니다. 기록이 없는 칸은 비워 둡니다 |
| 인계 요약 | 이전 활동보고서를 불러옴 | 출석 패턴, 과제 수행, 학습 태도, 수강 진도만 뽑아 다음 멘토에게 보낼 글로 만듭니다. 받은 멘토는 글을 붙여 넣어 두고 종합계획서를 쓸 때 참고합니다 |
| 사전 연락, 오프라인 일정·장소 | 멘티를 고르고 일정과 장소 확인 | 사전 연락 문자와, 매월 20일쯤 이음단에 보내는 일정·장소 문구를 만듭니다 (정해진 문구, AI 미사용) |
| 그 밖 | | 활동비 계산, 협약 장소 찾기 |

화면은 멘티 한 명의 일을 사전 연락부터 완료보고서까지 단계 순서대로 안내합니다. 멘토는 고르기와 짧은 메모만 하고, 날짜·지난 과제·이번 주 계획은 앞서 저장한 자료에서 채워집니다.

도구는 초안까지만 만듭니다. 멘토가 읽고 고친 뒤 플랫폼에 직접 제출합니다.

### 확인한 것

- 멘토가 물을 법한 질문 72개로 측정했습니다. 활동가이드에서 정답 근거를 상위 5개 안에 찾는 비율은 91.2%였고, 답할 수 있는 질문인지 판단을 맞힌 비율은 80.6%였습니다. 매뉴얼에 답이 없는 질문 8개 중 1개에서 답을 지어냈습니다. 자세한 수치는 `docs/rag_results.md`에 있습니다.
- 가상 보고서 14건에서 입력에 없는 날짜·점수를 만들어 내거나 이름·전화번호가 초안에 나온 경우는 없었습니다.
- 이 수치는 제안자가 직접 만든 가상 데이터로 잰 것입니다. 실제 멘토의 질문과 보고서로는 아직 확인하지 못했습니다.

> (작성 시간 측정 결과를 넣을 자리: 활동보고서, 종합계획서를 기존 방식과 도구로 작성한 시간)

## 3. 운영 부담을 어떻게 줄이나

- **반복 문의 감소:** 매뉴얼에 답이 있는 질문은 멘토가 스스로 해결합니다. 답이 없는 질문은 맞는 문의처(운영사무국, 이음단, 학습지원센터)로 안내해 잘못 온 문의를 줄입니다.
- **보완 요청 감소:** 실제 접속 시간 기재, 증빙 사진 수, 7일 기한, 1회차 종합계획서 첨부 같은 빠뜨리기 쉬운 항목을 제출 전에 알려 줍니다.
- **매뉴얼 보완 자료:** 도구가 답하지 못한 질문을 모으면 매뉴얼에서 빠진 부분이 드러납니다. 이 기능은 **기본으로 꺼져 있고**, 운영 기관과 협의한 뒤에만 켭니다. 켜면 다음과 같이 돌아갑니다.
  1. 개인정보를 가린 질문 문장만 모읍니다. 누가 물었는지는 저장하지 않습니다.
  2. 운영 측이 모인 질문에 답을 답니다.
  3. 그 답을 공지나 FAQ 문서로 만들어 도구의 자료에 넣습니다.
  4. 다음부터는 같은 질문에 도구가 답합니다.

## 4. 개인정보 위험을 어떻게 관리하나

멘티는 미성년자이므로, 처음부터 정보를 모으지 않는 쪽으로 설계했습니다.

| 원칙 | 구현 |
| --- | --- |
| 이름은 브라우저 밖으로 나가지 않는다 | 멘티 이름·학년과 멘토 이름·연락처는 멘토의 브라우저에만 저장합니다. 서버와 AI에는 `[멘티명]` 같은 자리표시만 오가고, 화면이 그 자리를 채웁니다. 멘티 연락처와 학교는 적는 칸이 없습니다 |
| 저장하지 않는다 | 질문과 보고서 내용은 서버의 DB, 로그, 캐시 어디에도 남기지 않습니다. 초안은 멘토의 브라우저에만 보관됩니다 |
| 가려서 보낸다 | 메모에 섞여 들어온 이름, 전화번호, 학교명은 AI에 보내기 전에 가립니다. 가정·정서·건강 이야기는 보고서 초안의 재료로 쓰지 않습니다 |
| 넘길 것만 넘긴다 | 인계 요약은 네 가지 항목만 만듭니다. 성적·이해도와 상담 내용은 넘기는 칸이 없습니다 |
| 위험 신호는 사람에게 | 아동 보호·안전 신호가 있는 질문에는 AI가 답하지 않고 운영사무국 즉시 보고를 안내합니다 |

남는 위험도 있습니다. 가리는 규칙이 모든 표현을 잡지는 못하고, 가린 글이라도 AI 제공사로 전달됩니다. 시범 운영 전에 서울시의 개인정보 검토를 받고, AI 제공사와의 계약 조건(데이터 보관·학습 미사용)을 확인해야 합니다. 구조와 점검 방법은 `docs/architecture.md`에 정리했습니다.

## 5. 단계별 도입안

| 단계 | 범위 | 확인할 것 |
| --- | --- | --- |
| 1. 사전 검토 | 운영사무국과 기능 시연, 개인정보 검토 | 답변 내용이 운영 기준과 맞는지, 문의처 구분이 맞는지 |
| 2. 시범 운영 | 자치구 한 곳의 희망 멘토 | 실제 질문에서의 정확도, 보고서 작성 시간, 보완 요청 건수 변화 |
| 3. 보완 | 시범 결과 반영 | 틀린 답변 유형, 자주 나온 답 없는 질문 |
| 4. 확대 | 전체 자치구 | 운영 주체와 유지 방법 (공지 갱신, 문의 대응) |

시범 운영 기간과 규모는 운영사무국과 협의해 정하겠습니다.

## 6. 요청드리는 협조

1. **활동가이드와 공지 사용 허락:** 도구는 활동가이드와 공지 본문을 정리해 근거로 씁니다. 지금은 비공개 저장소에서 개발용으로만 쓰고 있습니다.
2. **공식 FAQ와 확인:** 매뉴얼에 없어 답하지 못하는 질문이 있습니다(예: 학습사이트 변경 문의처, 회기 중 활동중단 시 이음단 통보 여부). 공식 답변을 받으면 자료에 넣겠습니다.
3. **서식과 플랫폼 정보:** 종합계획서 입력 칸의 글자 수 제한, 활동보고서의 실제 입력 화면, 친화·성장활동 신청서 문항을 알면 초안을 그에 맞출 수 있습니다.
4. **플랫폼 내 인계 기능 검토:** 지금은 이전 멘토가 인계 요약을 글로 복사해 운영사무국·이음단에 보내고, 새 멘토가 그 글을 받아 도구에 붙여 넣습니다. 이 도구는 매칭 정보를 알지 못하고 멘티 정보를 서버에 두지 않아서 자동으로 전달할 수 없습니다. 플랫폼에 인계 칸이 생겨 새 멘토가 배정될 때 인계 요약이 함께 전달되면 이 과정이 안전하고 간단해집니다.
5. **협약 장소 목록:** 오프라인 멘토링 장소를 자치구별로 보여 주는 화면이 있으나 지금은 예시 데이터입니다.

## 7. 한계

- 시제품입니다. 가상 데이터로만 확인했고 실제 멘토가 쓴 적은 없습니다.
- AI의 답은 틀릴 수 있습니다. 측정에서도 답이 일부만 있는 질문을 다 답한 것처럼 말한 경우가 있었습니다. 그래서 답변마다 근거 쪽수를 보여 주고, 보고서는 초안으로만 제공합니다.
- 공지가 새로 나오면 사람이 자료에 넣어야 합니다.
- AI 사용료가 듭니다. 시범 규모의 비용은 사용량을 본 뒤 산정하겠습니다.
