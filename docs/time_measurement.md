# 작성 시간 측정 기록표

도구를 쓰기 전과 후에 같은 작업이 몇 분 걸리는지 본인이 직접 재서 적는다. 관문 1의 마지막 항목이다.

## 재는 방법

- 같은 종류의 작업을 기존 방식으로 한 번, 도구로 한 번 한다. 두 번째가 익숙해져 빨라지는 것을 줄이려면 서로 다른 회차·멘티로 한다.
- 시작은 화면(또는 서식)을 연 때, 끝은 플랫폼에 붙여 넣을 수 있는 글이 완성된 때다. 도구 사용 시간에는 초안을 읽고 고치는 시간을 포함한다.
- 실제 멘티 내용으로 잴 때도 이 도구에는 이름·연락처·학교를 넣지 않는다.
- 작업마다 세 번 이상 재면 평균을 낼 수 있다.
