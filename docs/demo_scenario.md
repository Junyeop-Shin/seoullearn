# MVP 데모 시나리오와 녹화 대본

화면 녹화용이다. 네 장면을 순서대로 보여 주면 8~10분쯤 걸린다. 모든 입력은 지어낸 가상 내용이고, 실제 멘티 정보는 쓰지 않는다.

## 준비

1. `docker compose up -d frontend ai-server`를 실행하고 1분쯤 기다린다. 첫 질문은 검색 모델을 불러오느라 10초쯤 걸리므로, 녹화 전에 아무 질문이나 한 번 해 둔다.
2. `http://localhost:3000`에서 멘토 계정을 만든다. 아이디는 실명이 아닌 것으로 한다.
3. 설정 화면에 이음단 오픈채팅 주소를 넣는다. 데모용 가짜 주소: `https://open.kakao.com/o/sample123`
4. 보관함이 비어 있는지 확인한다.

같은 순서를 자동으로 눌러 보는 점검은 `node scripts/e2e_demo.mjs <폴더>`다.

## 장면 1. 매뉴얼 질문 (약 3분)

| 순서 | 입력 | 화면에서 보여 줄 것 | 말할 내용 |
| --- | --- | --- | --- |
| 1-1 답이 있는 질문 | `가람중 멘티가 20분 늦게 들어왔는데 어떻게 처리하나요?` | 답변, 근거 카드(활동가이드 쪽수), '가린 정보: 학교명' | "활동가이드에서 근거를 찾아 쪽수와 함께 답합니다. 학교 이름은 AI에 보내기 전에 가렸습니다." |
| 1-2 답이 없는 질문 | `활동인증서를 영문으로도 발급받을 수 있나요?` | '자료에 없습니다', 문의처 카드(운영사무국), 문의 초안과 복사 버튼 | "매뉴얼에 없는 내용은 지어내지 않고, 어디에 물어볼지와 보낼 글의 초안을 줍니다." |
| 1-3 이음단 연결 | `오프라인 멘토링 일정을 바꾸려면 누구한테 말해야 하나요?` | 문의처 카드(이음단), '이음단 오픈채팅 열기' 버튼 | "매칭 이후 운영 문의는 이음단으로 연결합니다. 오픈채팅 주소는 제 브라우저에만 저장돼 있습니다." |

## 장면 2. 활동보고서 초안 (약 2분)

활동보고서 화면에서 아래처럼 넣는다.

| 칸 | 입력 |
| --- | --- |
| 회차 상태 | 출석 |
| 멘토링 일자 / 진행 회차 | 2026-04-13 / 6 |
| 멘토링 과목 / 강좌명 | 수학 / 수학의 시작, 시발점 - 수1 |
| 진행시간 | 17:02~18:04 |
| 학습범위 / 학습목표 | T6 로그함수의 뜻과 그래프 / 로그함수와 지수함수의 역함수 관계 이해 |
| 학습진도 평가 / 출결 / 인강 / 과제 | 잘함 / 정시 / T6 수강 / Step1 T5 완료 |
| 학습이해도 평가 | 보통 |
| 멘토링 학습 내용 | `역함수 관계 그래프로 설명. 김민지 학생 어머님이 010-0000-0000로 시험범위 상담 원하심. 마지막에 부모님이랑 다퉈서 속상하다고 해서 얘기 들어줌` |

보여 줄 것과 말할 내용:

- '멘티 성명' 칸은 `[멘티명]` 자리표시다. "이름은 입력받지 않고, 플랫폼에서 직접 채웁니다."
- '가린 정보: 이름, 전화번호'와 정서 내용 경고. "메모에 섞인 이름과 전화번호는 가렸고, 가정 이야기는 보고서에 넣지 않았습니다."
- 5점 척도는 고른 그대로다. "평가는 멘토가 고른 값만 씁니다."
- 제출 안내(7일 기한 날짜, 증빙 사진 2장, 보호자 상담 가이드라인).
- 초안 한 칸을 고치고 '플랫폼에 복사'를 누른다.
- 별칭 `수학 고2 A`로 보관함에 저장한다. 활동보고서 화면을 다시 열면 다음 회차 번호가 채워져 있는 것을 보여 준다.

## 장면 3. 신규 멘티 종합계획서① (약 3분)

1. 사전 연락 화면: 유형 '온라인'으로 문자 초안을 만든다. `[멘티명]` 자리표시를 보여 주고 '문자 복사'를 누른다.
2. 내 멘티 화면: 통화에서 들은 내용을 아래처럼 적고 저장한다.

| 칸 | 입력 |
| --- | --- |
| 멘티 별칭 | 국어 고1 C |
| 멘토링 과목 / 유형 | 국어 / 온라인 |
| 학습사이트와 수강 강좌 | (가상) 고1 국어 문학 개념 |
| 멘토링 시간 / 학습 요일 / 1회차 일시 | 60 / 월 / 2026-10-12 20:00 |
| 이번 회기 목표 | 문학 감 잡기, 인강 끝까지 듣기 |
| 학습 상황 | 모의고사 국어 3~4등급, 문학이 약함 |

3. 종합계획서 화면: 별칭 `국어 고1 C`가 선택돼 있고 일정이 채워져 있는 것을 보여 준다. "이름이나 학교 없이 별칭으로만 구분하고, 이 브라우저에만 저장됩니다."
4. ① 강의 목차에 `synthetic/courses.json`의 C3 목차(1강~24강 제목)를 붙여 넣고 '강 목록으로 정리'.
5. ② 1회차 날짜 `2026-10-12`, 시험 기간 `2026-12-07`~`2026-12-11`을 넣고 '16회차 계획 만들기'. 시험 직전 회차가 '복습', 시험 주가 '시험기간'으로 잡힌 것을 보여 준다.
6. ③ 멘토링 시간·요일·시작일시가 멘티 정보에서 채워져 있는 것을 확인하고 초안을 만든다.

말할 내용: "몇 회차에 몇 강을 넣을지는 규칙이 계산하고, AI는 문장만 씁니다. 확인되지 않은 진단은 '1회차에 자세한 상담 예정'으로 둡니다." '플랫폼에 복사'를 눌러 등록 후 수정 불가 확인창을 보여 준다.

## 장면 4. 교체 멘티 종합계획서① (약 2분)

장면 3의 화면에서 '이전 멘토의 인계 요약'을 펼쳐 아래를 넣고 초안을 다시 만든다.

| 항목 | 입력 |
| --- | --- |
| 출석 패턴 | 8회 모두 정시 출석 |
| 과제 수행 | 단어 과제는 들쭉날쭉함 |
| 수강 강의와 진도 | 20강 중 8강까지 수강, 다음은 9강 |

말할 내용: "멘토가 바뀔 때는 이 네 가지만 넘깁니다. 성적이나 상담 내용은 넘기는 칸이 아예 없습니다." 학생진단에 출석·과제 경향이 반영된 것을 장면 3의 결과와 비교해 보여 준다.

## 마무리 (약 1분)

보관함 화면에서 별칭별 목록을 보여 주고, '파일로 내보내기' → '보관함 전체 삭제' → '파일에서 가져오기'를 차례로 누른다.

말할 내용: "초안은 서버가 아니라 이 브라우저에만 있습니다. 기기를 옮길 때는 파일로 옮깁니다."

## 알려진 한계 (질문이 나오면)

- 답변은 초안이다. 모델이 문장을 빼거나 줄이는 경우가 있어 멘토가 읽고 고쳐야 한다.
- 문의 초안에 질문에 없던 사유 문장이 붙는 경우가 있었다.
- 종합계획서②와 완료보고서·인계 요약 화면은 이 데모에 넣지 않았다 (②는 화면에 있고, 뒤의 둘은 2단계).
