# 시연 순서

운영사무국이나 심사자 앞에서 화면을 직접 보여 줄 때의 순서다. 영상은 찍지 않는다. 처음부터 끝까지 10분쯤 걸린다. 모든 입력은 지어낸 가상 내용이고, 실제 멘티 정보는 쓰지 않는다.

같은 순서를 자동으로 눌러 보는 점검은 `scripts/e2e_demo.mjs`다.

## 준비

1. `docker compose up -d frontend ai-server`를 실행하고 1분쯤 기다린다. 첫 질문은 검색 모델을 불러오느라 10초쯤 걸리므로, 시연 전에 아무 질문이나 한 번 해 둔다.
2. `http://localhost:3000`에서 멘토 계정을 만든다. 아이디는 실명이 아닌 것으로 한다.
3. 설정에 이음단 오픈채팅 주소를 넣는다. 시연용 가짜 주소: `https://open.kakao.com/o/sample123`
4. 내 멘티가 비어 있는지 확인한다 (남아 있으면 백업·복원에서 전체 삭제).

## 1. 매뉴얼 질문 (약 3분)

| 순서 | 입력 | 보여 줄 것 | 말할 내용 |
| --- | --- | --- | --- |
| 답이 있는 질문 | `가람중 멘티가 20분 늦게 들어왔는데 어떻게 처리하나요?` | 답변, 근거 카드(쪽수), '가린 정보: 학교명' | "활동가이드에서 근거를 찾아 쪽수와 함께 답합니다. 학교 이름은 AI에 보내기 전에 가렸습니다." |
| 답이 없는 질문 | `활동인증서를 영문으로도 발급받을 수 있나요?` | '자료에 없습니다', 문의처 카드, 문의 초안 | "매뉴얼에 없는 내용은 지어내지 않고, 어디에 물어볼지와 보낼 글의 초안을 줍니다." |
| 금액 질문 | `오프라인으로 고등학생 가르치면 시간당 얼마예요?` | 36,000원과 내역, 계산기 버튼 | "금액은 AI가 아니라 활동가이드 기준을 옮긴 계산 규칙이 답합니다." |

## 2. 멘티 등록과 사전 연락 (약 2분)

1. 내 멘티에서 별칭 `국어 고1 C`로 멘티를 추가한다. "이름이나 학교 없이 별칭으로만 구분합니다."
2. 기본 정보를 적고 저장한다.

| 칸 | 입력 |
| --- | --- |
| 멘토링 과목 / 유형 | 국어 / 온라인 |
| 학습사이트와 수강 강좌 | (가상) 고1 국어 문학 개념 |
| 멘토링 시간 / 학습 요일 / 1회차 일시 | 60 / 월 / 2026-10-12 20:00 |
| 이번 회기 목표 | 문학 감 잡기, 인강 끝까지 듣기 |
| 학습 상황 | 모의고사 국어 3~4등급, 문학이 약함 |

3. 화면 위쪽의 "다음 할 일" 안내와 16회차 목록(예상 날짜)을 보여 준다.
4. '사전 연락 문자'를 눌러 문자 초안을 만든다. `[멘티명]`, `[멘토 연락처]` 자리표시를 보여 준다.

## 3. 종합계획서① (약 2분)

1. 멘티 화면에서 '종합계획서 ①·②'를 누른다. 일정이 이미 채워져 있는 것을 보여 준다.
2. ① 강의 목차에 `synthetic/courses.json`의 C3 목차(1강~24강 제목)를 붙여 넣고 '강 목록으로 정리'. 강좌 이름을 적어 '내 강좌로 저장'한다.
3. ② 시험 기간 `2026-12-07`~`2026-12-11`을 넣고 '16회차 계획 만들기'. 시험 직전 회차가 '복습', 시험 주가 '시험기간'으로 잡힌 것을 보여 준다.
4. ③ 초안을 만든다. "몇 회차에 몇 강을 넣을지는 규칙이 계산하고, AI는 문장만 씁니다. 확인되지 않은 진단은 '1회차에 자세한 상담 예정'으로 둡니다."
5. '플랫폼에 복사'를 눌러 등록 후 수정 불가 확인창을 보여 주고, 저장한다.

## 4. 활동보고서 (약 2분)

멘티 화면에서 1회차를 누른다. 회차, 날짜, 과목, 강좌가 채워져 있다. 나머지를 아래처럼 넣는다.

| 칸 | 입력 |
| --- | --- |
| 진행시간 | 20:01~21:02 |
| 학습범위 / 학습목표 | 1강 문학 감상의 관점 / 감상의 관점 구분하기 |
| 학습진도 평가 / 출결 / 인강 / 과제 | 잘함 / 정시 / 1강 수강 / 첫 회차라 없음 |
| 학습이해도 평가 | 보통 |
| 멘토링 학습 내용 | `감상의 관점 네 가지 설명. 김민지 학생 어머님이 010-0000-0000로 상담 원하심. 마지막에 부모님이랑 다퉈서 속상하다고 해서 얘기 들어줌` |

보여 줄 것과 말할 내용:

- '멘티 성명' 칸은 `[멘티명]` 자리표시다. "이름은 입력받지 않고 플랫폼에서 직접 채웁니다."
- '가린 정보: 이름, 전화번호'와 정서 내용 경고. "메모에 섞인 이름과 전화번호는 가렸고, 가정 이야기는 보고서에 넣지 않았습니다."
- 제출 안내(7일 기한 날짜, 증빙 사진 2장, 종합계획서② 첨부).
- 한 칸을 고치고 저장한 뒤 멘티 화면으로 돌아간다. 1회차가 채워지고 "다음 할 일"이 바뀐 것을 보여 준다. 1회차를 다시 눌러 고친 내용이 남아 있는 것을 보여 준다.

## 5. 회기를 마칠 때 (약 1분)

- 완료보고서: 저장한 활동보고서로 회차별 수행 리스트가 채워지는 것을 보여 준다. 시연에서는 1건뿐이므로 "16회차를 쓰면 이렇게 채워집니다" 정도로 설명한다. (16건으로 보여 주려면 `synthetic/sessions_M1.json`을 붙여 넣기 형식으로 넣는다. 점검 스크립트가 그렇게 한다.)
- 인계 요약: "멘토가 바뀔 때는 출석 패턴, 과제 수행, 학습 태도, 수강 진도 네 가지만 넘깁니다. 성적이나 상담 내용은 넘기는 칸이 없습니다."
- 자료 관리: '이 멘티 자료 내보내기'와 '회기 정리'를 보여 준다. "자료는 서버가 아니라 이 브라우저에만 있습니다. 기기를 옮길 때는 파일로 옮기고, 회기가 끝나면 완료보고서와 인계 요약만 남기고 지웁니다."

## 알려진 한계 (질문이 나오면)

- 결과는 초안이다. 모델이 문장을 빼거나 줄이는 경우가 있어 멘토가 읽고 고쳐야 한다.
- 문의 초안에 질문에 없던 사유 문장이 붙는 경우가 있었다.
- 협약 장소는 예시 데이터이고, 지도는 배포 주소를 카카오에 등록한 뒤에 뜬다.
